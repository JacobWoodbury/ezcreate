# ezcreate (Bevy)

Townscaper-style modular building sandbox — Bevy port of the Godot **builder** project.

## Quick start

```sh
cargo run
```

First compile can take several minutes.

## Controls

See [PORT.md](PORT.md) for the full control list and port status.

## Source

- **Godot reference:** `~/Documents/builder`
- **Port spec:** `PORT.md` and `docs/`

## Mods

- Built-in: `assets/mods/sample_pack/mod.json`
- User mods: `~/Library/Application Support/ezcreate/mods/`
